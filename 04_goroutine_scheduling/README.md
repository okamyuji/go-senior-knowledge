# ゴルーチンスケジューリング

GoランタイムはM:Nスケジューリングモデルを採用しており、多数のゴルーチン(G)を少数のOSスレッド(M)上で効率的に実行します。
スケジューラはプロセッサ(P)という論理的な実行単位を通じてゴルーチンを管理しています。

# ゴルーチン数の観測

GoroutineCount関数は、n個のゴルーチンを起動してからruntime.NumGoroutineで現在のゴルーチン数を取得します。
すべてのゴルーチンがチャネルで待機している間にカウントするため、少なくともn以上の値が返されます。
テスト用ゴルーチンやランタイム内部のゴルーチンも含まれるため、正確にnとは限りません。

# プロセッサ情報の取得

ProcessorCount関数は、runtime.GOMAXPROCS(0)で現在のGOMAXPROCS設定を、runtime.NumCPUで論理CPU数を取得して返します。
GOMAXPROCSは同時に実行可能なOSスレッド数の上限を表しており、デフォルトではNumCPUと同じ値に設定されます。
GOMAXPROCS(0)のように引数に0を渡すと、現在の設定値を変更せずに取得できます。

# 並列ワークの実行

ParallelWork関数は、n個のゴルーチンがそれぞれ自分のインデックスの二乗を計算し、チャネル経由で結果を返します。
各結果にはインデックスが付随しているため、受信側で正しい位置にスライスへ格納できます。
チャネルのバッファサイズをnに設定することで、送信側のゴルーチンがブロックせずに完了できるようにしています。

# テストの実行方法

以下のコマンドでテストを実行できます。

```
go test -v ./04_goroutine_scheduling/...
```
