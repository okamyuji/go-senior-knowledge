# チャネルのクローズ

このパッケージでは、チャネルを閉じる操作に関連する3つのパターンを示しています。

## Producer-Consumerパターン

ProducerConsumerは、goroutineで動作するproducerがすべての値を送信した後にチャネルを閉じ、consumer側がfor-rangeループで受信する典型的なパターンを実演しています。for-rangeはチャネルが閉じられると自動的にループを終了します。

## 閉じたチャネルからの受信

ReceiveFromClosedは、閉じた空のチャネルから受信した場合の動作を実演しています。この場合、型のゼロ値(intなら0)が返され、2番目の戻り値okはfalseになります。この挙動を利用することで、チャネルが閉じられたかどうかを判定できます。

## Fan-Inパターン

FanInは、複数の入力チャネルを1つの出力チャネルに合流させるパターンを実演しています。各入力チャネルに対して1つのgoroutineを起動し、sync.WaitGroupですべての入力チャネルが完了したことを確認してから出力チャネルを閉じます。この手法はパイプラインの合流点で広く使われています。
