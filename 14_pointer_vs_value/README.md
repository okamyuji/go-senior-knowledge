# ポインタレシーバと値レシーバ

## 概要

Goではメソッドのレシーバとしてポインタレシーバと値レシーバのどちらかを選択します。この選択はメソッドセット、インターフェースの充足、値のコピーセマンティクスに影響を与えます。

## ポインタレシーバと値レシーバの違い

ポインタレシーバのメソッドは元の値を直接操作します。値レシーバのメソッドはレシーバのコピーを受け取るため、元の値には影響しません。

```go
func (c *Counter) Increment() { c.N++ }  // 元の値を変更します
func (c Counter) Value() int { return c.N } // コピーを読み取ります
```

## メソッドセットのルール

型Tのメソッドセットには値レシーバのメソッドだけが含まれます。型*Tのメソッドセットにはポインタレシーバと値レシーバの両方のメソッドが含まれます。

この違いはインターフェースの充足に直接影響します。ポインタレシーバのメソッドを要求するインターフェースに対して、値型を代入することはできません。

## インターフェースの充足

```go
type Incrementer interface { Increment() }
type Valuer interface { Value() int }

var c Counter
var _ Valuer = c      // OK: 値レシーバのみのインターフェースは値で充足できます
var _ Valuer = &c     // OK: ポインタでも充足できます
var _ Incrementer = &c // OK: ポインタレシーバのインターフェースはポインタで充足できます
// var _ Incrementer = c // コンパイルエラーになります
```

## 使い分けの指針

構造体のフィールドを変更する必要がある場合や、構造体が大きくコピーコストを避けたい場合はポインタレシーバを使用します。構造体が小さく読み取り専用の場合は値レシーバを使用します。
