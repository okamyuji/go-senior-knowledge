# チャネルの内部動作

このパッケージでは、Goチャネルの基本的な動作を3つのパターンで示しています。

## アンバッファードチャネル

UnbufferedChannelは、容量0のチャネルを使ったgoroutine間の同期的な値の受け渡しを実演しています。送信側は受信側が準備できるまでブロックし、受信側は送信側が値を送るまでブロックします。この同期的なハンドシェイクにより、happens-before関係が保証されます。

## バッファードチャネル

BufferedChannelは、容量付きチャネルを使った非同期送信を実演しています。バッファに空きがある限り、送信はブロックせずに完了します。このコードでは、スライスの長さと同じ容量を確保しているため、受信側のgoroutineがなくてもすべての値を送信できます。値はFIFO順序で取り出されます。

## チャネルの方向指定

ChannelDirectionは、chan<-(送信専用)と<-chan(受信専用)という方向指定付きチャネル型を実演しています。関数シグネチャでチャネルの方向を制限することで、producer関数が誤って受信したり、consumer関数が誤って送信したりするミスをコンパイル時に検出できます。
