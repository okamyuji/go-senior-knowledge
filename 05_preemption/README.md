# プリエンプション

Goのスケジューラはゴルーチンの実行を中断して他のゴルーチンに切り替える機能を備えています。
Go 1.14以降では非同期プリエンプションが導入され、明示的な譲渡ポイントがないCPUバウンドなゴルーチンも中断できるようになりました。

# 協調的な譲渡

CooperativeYield関数は、ループの各反復でruntime.Goschedを呼び出してプロセッサを自発的に譲渡します。
Go 1.14より前のバージョンでは、関数呼び出しやチャネル操作といった協調ポイントでのみゴルーチンの切り替えが行われていました。
runtime.Goschedを呼ぶことで、他のゴルーチンに実行の機会を明示的に与えることができます。

# 非同期プリエンプション

PreemptibleWork関数は、ループ内で単純な加算を繰り返すCPUバウンドな処理です。
Go 1.14以降のランタイムはシグナルベースの非同期プリエンプションを使用するため、このような処理中でもスケジューラがゴルーチンを中断できます。
この仕組みにより、1つのゴルーチンがプロセッサを長時間独占してしまう問題が解消されています。

# 並行タスクの完了確認

ConcurrentTasks関数は、n個のゴルーチンを起動してそれぞれ異なる範囲の総和を計算させます。
すべてのゴルーチンがプリエンプションの対象となるため、スケジューラが公平に実行時間を配分します。
WaitGroupで全ゴルーチンの完了を待ってからチャネルを閉じることで、すべての結果を確実に収集しています。
