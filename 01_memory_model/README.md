# Goのメモリモデル

Goのメモリモデルは、あるゴルーチンで変数に書き込んだ値が別のゴルーチンから読み取れる条件を定義しています。
同期なしに複数のゴルーチンから同じ変数にアクセスすると、プログラムの動作は保証されません。

# 同期付きカウンタ

sync.Mutexとsync.WaitGroupを使うことで、複数のゴルーチンから共有カウンタを安全にインクリメントできます。
Mutexのロックとアンロックがhappens-before関係を構築するため、すべての書き込みが正しく反映されます。

SynchronizedIncrement関数では、n個のゴルーチンがそれぞれカウンタを1回インクリメントします。
WaitGroupですべてのゴルーチンの完了を待ってから最終値を返すため、結果は常にnと一致します。

# チャネルによる可視性保証

チャネルの送信は、対応する受信よりも前に発生することがGoの仕様で保証されています。
この性質を利用すると、チャネル送信前の変数への書き込みが受信側から確実に見えるようになります。

ChannelVisibility関数では、ゴルーチン内で変数に42を代入した後にチャネルへ送信しています。
メイン側でチャネルから受信した時点で、変数の値42が確実に見える状態になります。
