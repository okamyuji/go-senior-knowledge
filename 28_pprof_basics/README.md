# pprofによるプロファイリング基礎

runtime/pprofパッケージを使うことで、GoプログラムのCPU使用率やメモリ割り当てをプロファイリングできます。パフォーマンスのボトルネックを特定するための基本的なツールです。

# CPUプロファイル

CPUプロファイルはプログラムのどの関数がCPU時間を消費しているかを記録します。StartCPUProfile関数でプロファイリングを開始し、計測対象の処理を実行した後にStopCPUProfile関数で停止します。

CPUIntensiveWork関数では再帰的なフィボナッチ計算を行ってCPU負荷を生成しています。プロファイルを取得することで、この関数がCPU時間の大部分を占めていることを確認できます。

# ヒーププロファイル

ヒーププロファイルは現在のメモリ割り当ての状況をスナップショットとして記録します。WriteHeapProfile関数を呼ぶことで、その時点でのヒープの状態を取得できます。

MemoryIntensiveWork関数ではループ内でスライスを繰り返し確保しています。ヒーププロファイルを分析することで、どのコードパスが多くのメモリを割り当てているかを特定できます。

# プロファイルの分析方法

収集したプロファイルファイルはgo tool pprofコマンドで分析します。対話型のCLIモードではtopコマンドで上位の関数を表示でき、listコマンドでソースコードにアノテーションを付けて表示できます。

-httpフラグを指定するとブラウザ上でコールグラフやフレイムグラフを表示できます。

# Webサーバーでの継続的プロファイリング

net/http/pprofパッケージをインポートするだけで、/debug/pprof/エンドポイントが追加されます。本番環境のサーバーに組み込んでおくことで、いつでもプロファイルを取得できます。
