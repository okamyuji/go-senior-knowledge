# 空インターフェース(any)と型アサーション

Goの空インターフェースanyはすべての型を受け入れることができます。
内部的には型ポインタとデータポインタのペアとして表現されており、具体的な値を格納する際にはボクシングが行われます。

# 安全な型アサーション(comma-okイディオム)

TypeAssertSafe関数では、comma-okイディオムを使って型アサーションの成否を安全に判定しています。
val, ok := i.(Type)の形式を使うと、型が一致しない場合でもpanicせずにokがfalseを返します。
okがfalseのとき、valにはその型のゼロ値が入ります。

# 型スイッチによる分岐

TypeSwitch関数では、switch v := i.(type)を使って動的型に応じた処理を分岐しています。
int、string、boolのそれぞれに対応したcase節で処理を行い、未知の型はdefault節で型名を返します。

# comma-okなしの型アサーションによるpanic

AssertionPanic関数では、comma-okを使わずにi.(int)を直接呼び出しています。
動的型がintでない場合はランタイムpanicが発生するため、型が確実にわかっている場合以外はcomma-okイディオムを使うべきです。

# StoreAnyとボクシング

StoreAny関数はany型の引数を受け取り、そのまま返します。
intのような具体型をany型に代入すると、ランタイムが型情報とデータをペアにしたインターフェース値を作成します。
この変換をボクシングと呼び、ヒープアロケーションが発生する場合があります。
