# select文の動作

このパッケージでは、Goのselect文が持つ3つの重要な動作パターンを示しています。

## 複数ケースが同時に準備完了した場合

SelectMultipleReadyは、2つのチャネルに同時にデータがある状態でselectを実行します。Goのランタイムは準備完了した複数のケースの中から擬似ランダムに1つを選択します。この動作により、特定のチャネルが常に優先されるstarvation(飢餓状態)を防いでいます。

## defaultケースによるノンブロッキング操作

SelectWithDefaultは、defaultケースを含むselectを使って、チャネルにデータがない場合でもブロックせずに即座に処理を返す方法を実演しています。ポーリングやノンブロッキングな送受信が必要な場面で活用します。

## time.Afterによるタイムアウト

SelectWithTimeoutは、time.Afterが返すチャネルをselectのケースに組み込むことで、指定時間内にデータが届かなければタイムアウトとして処理を打ち切るパターンを実演しています。ネットワーク通信やリソース待ちの場面で広く使われます。
