# ジェネリクス

## 概要

Go 1.18で導入された型パラメータ(ジェネリクス)を使うと、異なる型に対して同じロジックを適用する関数やデータ構造を、型安全性を保ったまま記述できます。このパッケージでは、制約インターフェースの定義、汎用関数(Min, Map, Filter)、汎用データ構造(Stack)の実装パターンを示します。

## 型制約の定義

ジェネリック関数では、型パラメータに対して使用可能な操作を制約インターフェースで指定します。以下のOrdered制約は、比較演算子(<)が使える型を表しています。

```go
type Ordered interface {
    ~int | ~float64 | ~string
}
```

チルダ(~)を付けると、基底型がintやfloat64である派生型も許可されます。例えば、type MyInt intと定義した型もOrdered制約を満たします。

## Min関数

Min関数は2つの値を受け取り、小さい方を返します。型パラメータTがOrdered制約を持つため、<演算子をコンパイル時に安全に使用できます。

```go
func Min[T Ordered](a, b T) T {
    if a < b {
        return a
    }
    return b
}
```

int, float64, stringのいずれでも同じMin関数を呼び出すことができます。

## MapとFilter

Map関数はスライスの各要素に変換関数を適用し、新しいスライスを返します。Filter関数は述語関数がtrueを返す要素だけを含む新しいスライスを返します。

どちらもany制約を使うため、任意の型に対して使用できます。関数型のパラメータを組み合わせることで、変換や選択のロジックを呼び出し側で柔軟に指定できます。

## Stack型

Stackは型パラメータを持つ汎用LIFOデータ構造です。ゼロ値がそのまま空のスタックとして使えるように設計されています。

```go
var s Stack[int]
s.Push(42)
val, ok := s.Pop() // 42, true
```

Push, Pop, Peek, Lenの4つのメソッドを提供します。Popは空のスタックに対して呼び出されたとき、ゼロ値とfalseを返します。

## ジェネリクスを使うべき場面

型パラメータは、ロジックが同一で扱う型だけが異なる場合に効果を発揮します。単に異なる型を受け取るだけであればinterface{}やanyで十分ですが、型安全性を保ちたい場合にはジェネリクスを使ってください。

逆に、型ごとに異なる振る舞いが必要な場合は、インターフェースを使った多態の方が適切です。ジェネリクスは万能ではなく、コードの読みやすさとのバランスを考えて使用してください。
